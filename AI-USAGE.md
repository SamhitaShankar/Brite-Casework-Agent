# AI Usage Declaration

This project was developed with the assistance of an Agentic AI system (Antigravity).

## Code Generation
- The React frontend (UI components, state management) was primarily generated by the AI based on user requirements.
- The FastAPI backend routing and database schema boilerplate were drafted by the AI.
- The `PolicyEngine` logic and JSON ruleset was extracted and generated by the AI under explicit guidance.

## Architecture & Design
- The AI was used to consult on production-readiness, UI/UX polish (e.g., adding visual feedback to the Refresh button), and ensuring the architectural design met the Hackathon rubric's strict requirements (e.g., hard short-circuiting LLM calls).

## Manual Work
- Domain logic validation and policy interpretation.
- Final review and verification of all generated code to ensure no hallucinations or incorrect assumptions were included in the rule engine.
